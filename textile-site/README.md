# 锦源纺织 · 企业官网

浙江柯桥源头面料工厂的**单页响应式官网**，前沿编辑排版风格（Editorial / Swiss Modern）。

## 设计特征

- **巨型标题 + 描边斜体字**：`春秋` 使用 `-webkit-text-stroke` 空心效果，时装杂志常用手法
- **朱砂红点睛色** `#d8492b`：在米白纸感底色上形成强对比，克制而高级
- **跑马灯**：面料品类无缝横向滚动（`@keyframes marq`）
- **编号列表产品区**：`01–06` 编号 + 悬停整行位移，替代传统卡片
- **超大数字 + 上标单位**：`20⁺` / `8000ᵀ`，瑞士排版感
- **竖排英文侧标**：`Zhejiang · Keqiao — Since 2003`，编辑感细节
- **滚动入场动效**：`IntersectionObserver` 驱动的 `.reveal` 位移淡入，支持 `.d1–.d4` 阶梯延迟
- **无任何外部依赖**：单文件，纯原生 HTML/CSS/JS，无 CDN、无框架

## 内容区块

| 区块 | 说明 |
|---|---|
| Hero | 巨型标题 + 杂志式图块组 + 滚动提示 |
| 跑马灯 | 六类面料无缝滚动 |
| About | 分栏编辑排版 + 四项核心数据 |
| Products | 编号列表式六类面料 |
| Advantages | 深色区块，2×2 大留白网格 |
| Contact | 左侧信息栏（带英文小标签）+ 右侧表单 |
| Footer | 超大标语 + 链接组 |

## 技术说明

- **响应式断点**：1100px / 768px，移动端隐藏侧标与导航链接
- **字体栈**：`-apple-system` → `SF Pro Display` → `PingFang SC` → `Microsoft YaHei`
- **图片策略**：为避免外链失效，视觉图块使用 CSS 渐变 + 织纹模拟（`repeating-linear-gradient`），替换为实拍图可获得最佳质感
